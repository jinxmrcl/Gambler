# Cooldowns

`/cooldowns` shows your remaining time on every tracked cooldown-based command
([work/crime/slut/rob](../Economy/Hustle%20%28Work%20Crime%20Rob%29.md),
[dungeon](../RPG%20Overview.md), duel). All cooldowns are persisted in the database, so a bot
restart doesn't reset them. See [Admin Overview](Admin%20Overview.md).
