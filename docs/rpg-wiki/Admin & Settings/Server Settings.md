# Server Settings

- `/settings` — shows current server configuration
- `/togglegame` — enable/disable a specific [[../Casino Games/Casino Overview|casino game]] per-guild
- `/togglechannel` — restrict games to specific channels
- `/set-gamblechannel` — restrict the **entire bot** (not just games) to one channel;
  administrators are always exempt so they can reconfigure it

See [[Admin Overview]].
