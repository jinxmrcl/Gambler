# Blackjack 🃏

Classic Blackjack with Hit / Stand / Double buttons, interactive via Discord Components V2.

- Natural blackjack (2-card 21) pays **2.5x**
- Regular win pays **2x**, push refunds the bet
- Double down doubles the bet and draws exactly one more card
- Dealer draws to 17
