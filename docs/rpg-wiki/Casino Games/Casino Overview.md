# Casino Overview

All games share a fixed **3% house edge** (`HOUSE_EDGE` in `utils/economy.py`), applied to fair payout multipliers so every game is mathematically transparent.

Server admins can disable individual games per-guild — see [Server Settings](../Admin%20%26%20Settings/Server%20Settings.md). Toggleable games: `blackjack`, `mines`, `hilo`, `plinko`, `limbo`, `keno`, `slots`, `roulette`, `dice`, `soloflip`, `scratchcard`, `horserace`, `baccarat`.
