# Mage 🔮

A spellcaster with devastating magic but a fragile body.

## Base stats (level 1)
- HP: 80 (+8/level)
- ATK: 23 (+3/level)
- DEF: 4 (+1/level)
- Crit: 10%

## Skill
**Arcane Bolt** — The first attack of every fight is a guaranteed critical hit.

See [[Combat System]] for how skills interact with the damage formula, and [[Equipment & Upgrades]] for gearing this class.
