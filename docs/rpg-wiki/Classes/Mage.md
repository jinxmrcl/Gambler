# Mage 🔮

A spellcaster with devastating magic but a fragile body.

## Base stats (level 1)
- HP: 80 (+8.26/level)
- ATK: 23 (+2.75/level)
- DEF: 4 (+1.84/level)
- Crit: 10%

## Skill
**Arcane Bolt** — The first attack of every fight is a guaranteed critical hit.

See [Combat System](../Combat%20System.md) for how skills interact with the damage formula, and [Equipment & Upgrades](../Equipment%20%26%20Upgrades.md) for gearing this class.
